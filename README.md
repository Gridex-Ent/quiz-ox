# OX 퀴즈 라이브

새 컴퓨터에서 이어서 작업하려면 **[PC 이관 및 GPT-SoVITS 음성 제작 인계](DOCS/planning/pc-migration-gpt-sovits.md)**를 먼저 읽으세요. 참고 음성과 브라우저 설정은 별도로 옮겨야 합니다.

**다른 PC에서 생성 음성으로 실행:** **Code → Download ZIP**으로 받고 [사용 안내](DOCS/planning/voice-release-2026-10-21.md)를 확인하세요. 시작·문제·정답·마무리 WAV 38개는 `audio/2026-10-21`에 제공합니다. 전체 음성의 사람 청취 검수는 미완료이므로 행사 전에 확인하세요. 원본 참고 음성과 학습 모델은 공개하지 않습니다.

문제 음성은 번호나 ‘문제입니다’ 안내 없이 바로 지문으로 시작합니다. [자동 검수 보고서](DOCS/planning/voice-audio-qa-2026-10-21.json)에 실제 WAV 해시, 브라우저 재생 검사 결과와 우선 청취할 파일을 기록했습니다. 숫자·고유명사의 자동 전사 차이가 남아 있어 검수용으로 배포합니다.

## 오프라인 손들기 진행

### 연회장용 HTML 단독 실행 (권장)

프로젝트 폴더의 **`OX퀴즈.html`을 더블클릭**합니다. Node.js, 설치, 인터넷, 서버 없이 이 파일 하나만으로 실행됩니다. 관리자에서 **프로젝션 창 열기**를 누르고 창을 빔프로젝터 화면으로 옮긴 다음 F11을 누르세요. Windows 디스플레이는 **확장**으로 설정하고 관리자 창을 행사 중 계속 열어 두세요.

문제 표시 → 손들기 확인 → 정답 공개 → 다음 문제 순서로 진행합니다. 타이머는 선택 사항입니다. 문제 편집 패널에서 직접 입력하거나 CSV/JSON을 불러온 뒤 **문제 적용**을 누르세요. HTML 단독 버전은 아래 개발용 서버 버전과 별도로 문제를 저장하므로, 기존 문제는 CSV/JSON으로 가져오세요. 브라우저의 파일 저장 정책에 따라 자동 저장이 제한될 수 있으므로 행사 전 **적용된 문제 백업**으로 JSON을 저장하세요.

#### GPT-SoVITS 등에서 만든 녹음 음성 연결

**생성 음성은 `audio/2026-10-21`에 별도 제공하며 HTML에 내장하지 않습니다.** 음성을 연결하기 전 기본 재생은 PC 음성입니다. 준비된 MP3/WAV를 관리자 화면의 **녹음 음성 불러오기**에서 연결하면, 해당 대본의 큐부터 녹음을 재생합니다. 등록하지 않은 대본은 기존 PC 음성을 사용합니다. 참고용 원본 음성은 퀴즈 낭독 파일로 자동 사용하지 않습니다.

1. 문제·정답·손 방향·대본을 확정하고 **음성 제작용 대본 JSON 저장** 또는 **전체 대본 TXT 저장**으로 내보냅니다. JSON의 각 `text`가 실제 낭독할 대본입니다. TXT에도 파일 이름이 표시됩니다.
2. GPT-SoVITS 등에서 각 대본을 그대로 음성으로 만들고 MP3/WAV로 내려받습니다. 파일 이름은 `intro.wav`, `question-01.wav` ~ `question-18.wav`, `answer-01.wav` ~ `answer-18.wav`, `closing.wav`로 지정합니다. 확장자는 `.mp3`도 가능합니다. 문제를 늘리면 번호도 이어집니다.
3. **음성 파일 + 대본 JSON 함께 불러오기**에서 음성과 제작에 쓴 JSON을 함께 선택합니다. JSON이 없으면 실제 녹음이 현재 대본과 같은지 직접 확인한 뒤 확인란을 선택하고 음성 파일을 불러옵니다. 일부 파일만 등록해도 됩니다.
4. 파일별 상태를 확인하고 문제를 선택해 **현재 대본 다시 읽기**로 점검합니다. 정답·해설은 정답 공개 뒤 재생합니다. 녹음이 실제로 끝난 후 문제 타이머가 시작되며, 중지·문제 변경 뒤에 뒤늦은 재생 종료가 타이머를 시작하지 않습니다.

JSON 비교는 제작용 대본과 현재 대본의 **텍스트 일치 확인**입니다. 실제 녹음의 발화 내용까지 검증하지 않으므로, 행사 전에 각 파일을 직접 들으세요. 등록 후 대본 또는 자동 대본의 손 방향 등이 바뀌면 기존 녹음을 사용 중지하고 안내합니다. 손상된 파일이나 재생 실패를 PC 음성으로 조용히 대체하지 않습니다. 파일을 다시 불러오거나 **현재 대본 다시 읽기**로 재시도하고, 필요하면 **PC 음성으로 읽기** 또는 직접 읽은 뒤 **낭독 완료**로 진행하세요. 마지막 5초 숫자는 기존 PC 음성입니다.

**불러온 음성은 현재 관리자 창의 메모리에만 있습니다.** 새로고침하거나 창을 닫으면 다시 선택해야 하며 HTML, JSON 문제 백업, 브라우저 저장소에는 음성 파일이 저장되지 않습니다. 행사 PC에 원본 MP3/WAV와 제작용 JSON을 보관하세요. 파일은 서버로 전송하지 않으며 등록 후 재생에 인터넷이 필요하지 않습니다. 재생 속도 설정은 PC 음성에만 적용되고 녹음은 원래 속도로 재생합니다.

#### 행사 문제와 대본 진행 (2026-10-21 반영)

`D:\Codex_Personal\ox_quiz\quiz-ox\questions\kiee-a-2026-quiz.md`의 **정규 16문제**를 가져왔습니다. 이 원본 폴더는 변경하지 않았습니다. 복사한 원문은 `questions/kiee-a-2026-quiz.md`, 실행용 데이터는 `questions/kiee-a-2026-offline.json`입니다. 원문의 16문제는 사실관계를 재검증하지 않았습니다. 2026-10-21 사용자 요청으로 배구단·노래 2문제를 추가해 **현재 총 18문제**입니다. 추가 문제와 실행 순서는 [추가 문제·배치표](questions/kiee-a-2026-additions.md)를 참고하세요.

- 1~6번 10초, 7~18번 5초. 1번은 맛보기입니다. 원문 5번인 현재 6번(페이커) 뒤 패자부활전 문항은 원문에서도 미정이므로 자동으로 끼워 넣지 않았습니다.
- 3번은 **한국전력 배구단의 이름은 전기스파이크다**(정답 X — 빅스톰). 9번은 **노래의 빈칸 고르기**, 보기 **빛 / 전기**(정답 빛)로 임시 배치했습니다. 노래를 먼저 부른 뒤 9번 문제 큐를 누르세요.
- 16번은 **딥러닝 / 침수**(정답 침수), 18번은 **박종배 / 장길수**(정답 박종배). 문제별 보기 두 개를 자유롭게 편집할 수 있습니다.
- 확정·번호 임시·제안·후보 상태와 진행 메모는 관리자에게만 표시합니다. 8번 달리기 지문은 원문의 후보 상태입니다. 원문의 오프닝·예비 문제는 정규 18개에 섞지 않았습니다.
- 기존에 사용자가 저장한 문제는 보존합니다. 예전 기본 예시 세 문제만 행사 문제집으로 자동 교체합니다. 이전 16문제 또는 다른 문제를 저장했던 경우 먼저 백업한 뒤 **행사 18문제 불러오기 → 문제 적용**을 누르세요. 편집한 내용이 있다면 백업과 비교해 옮겨 주세요.

문제 번호가 바뀌었으므로 음성 제작용 JSON/TXT를 다시 내보내세요. 현재 기본 대본은 **38개**이며 이전 준비 ZIP의 34개 기본 대본은 구버전입니다.

HTML의 큰 **다음 · 큐** 버튼으로 `시작 인사 → 문제 낭독 → 타이머 → 정답·해설 낭독 → 다음 문제 → 마무리`를 진행합니다. 문제 낭독이 끝나야 타이머가 시작되며, 시간이 끝나도 **다음 큐 전에는 정답을 공개하지 않습니다**. 낭독·타이머 도중 중복 다음 입력은 문제를 건너뛰지 않습니다.

- **발표 리모컨**: 관리자 또는 프로젝션 창을 클릭한 상태에서 PageDown / 오른쪽 화살표 / Space. 입력·편집 칸에 커서가 있으면 단축키를 실행하지 않습니다. PowerPoint 파일을 제어하는 기능이 아니라 프레젠터가 보내는 키 입력을 받는 기능입니다.
- **준비된 대본**: 기본 이름은 사용자가 요청한 아스트라입니다. 이름과 대본을 편집할 수 있습니다. PC에 설치된 한국어 음성으로 읽으며, 원본의 실시간 AI 음성과는 다릅니다. 음성이 없거나 낭독을 끄면 사회자가 직접 읽은 뒤 **낭독 완료**를 누릅니다. 전체 대본을 TXT로 저장할 수 있습니다.
- **음성 큐**: 사용자가 버튼으로 마이크를 켭니다. 브라우저가 기기 내 한국어 인식을 지원하고 언어 모델이 이미 설치된 경우에만 `큐` 또는 `문제 나갑니다. 큐!`를 받습니다. 미지원·권한 거부 시 안내하고 버튼/리모컨을 계속 사용할 수 있습니다. 클라우드 인식으로 전환하거나 모델을 자동 다운로드하지 않습니다. 낭독 중·직후에는 자체 음성을 큐로 오인하지 않도록 차단합니다.
- **음악·효과음**: 내장 합성 배경음악, 문제·정답·종료·마무리 효과음, 마지막 5초의 큰 숫자와 숫자 음성을 사용합니다. 숫자 음성은 설정에서 끌 수 있습니다. 음악은 낭독 중 줄이고, 음성 큐 대기 중에는 쉽니다. 소리는 관리자 창에서만 재생합니다.
- **진행 멈춤 / Escape**: 낭독·음악·음성 큐를 멈추고 진행 중 타이머를 일시정지합니다. **화면 가리기**도 진행을 멈추며, 다시 켠 뒤 버튼으로 재개합니다.

HTML은 외부 파일이나 서버 없이 동작합니다. 소스 변경 후 `npm run build:offline`로 단일 HTML을 다시 생성합니다. 개발용 React `/offline` 화면에도 문제집과 문제별 보기를 반영했으며, 위 대본·리모컨·음악 기능은 **HTML 단독 버전**에 구현했습니다.

원본 폴더에는 GitHub에 올라가지 않은 그리덱스 공동 사회 코드(수동 통화 큐 전달 및 서버 기반 음성 연결)가 있습니다. 이 HTML은 사용자의 최신 요청에 맞춘 준비 대본 낭독 방식입니다.

### 개발용 로컬 서버 실행

Windows에서 `start-offline.cmd`를 더블클릭하거나 `npm run offline`을 실행합니다. 설치된 Node.js와 프로젝트 의존성을 사용하며 인터넷과 게임 서버, 참가자 접속은 필요 없습니다. 실행 창은 행사 중 열어 두세요.

- 관리자: http://127.0.0.1:5173/offline
- 프로젝션: 관리자에서 **프로젝션 창 열기** → 같은 브라우저의 새 창을 보조 화면으로 이동 → F11. Windows 화면 설정은 **확장**으로 선택합니다.
- 기본 규칙: 참가자 본인 기준 **왼손 O · 오른손 X**. 준비 화면에서 반대로 변경할 수 있습니다.
- 문제 표시 → 필요시 타이머 시작 → 손들기 확인 → 정답 공개 → 다음 문제 순서로 진행합니다. 시간이 끝나도 정답은 자동 공개되지 않습니다.
- 문제 편집과 CSV/JSON 불러오기 후 **문제 적용**을 누릅니다. CSV는 `문제,정답,제한시간,해설` 헤더를 사용하며 기존 샘플 CSV도 지원합니다. 이미지 열은 사용하지 않습니다.
- 적용된 문제와 진행 상태는 브라우저에 저장됩니다. 문제 백업은 JSON으로 내려받으며 다시 불러올 수 있습니다. 브라우저 데이터를 지우기 전에 백업하세요.
- 두 화면은 같은 PC·브라우저·주소에서 동기화됩니다. 다른 브라우저나 시크릿 창을 섞지 마세요. 참가자 명단·자동 채점 없이 사회자가 탈락·부활·우승자를 판정합니다.


행사장에서 진행하는 OX 생존 퀴즈를 **참가자 스마트폰 + 대형 스크린 + 사회자 콘솔**로 옮긴 실시간 웹 게임입니다.

참가자는 QR로 접속해 이름과 휴대폰 번호를 넣고 입장합니다. 문제가 나오면 각자 폰에서 O 또는 X를 누르고, 대형 스크린에서는 참가자의 아바타가 O·X 구역으로 뛰어갑니다. 틀리면 대기실로 가고(관전), 중반에 열리는 패자부활전에서 맞히면 무대로 돌아옵니다. 오답이 누적 두 번이면 탈락하며, 생존자가 3명 이하가 되면 축하 화면으로 결승 진출자를 발표합니다.

## 주요 기능

- **실시간 진행** — 서버가 타이머·판정의 단일 기준. 문제를 공개하면 3초 준비 카운트 뒤 타이머가 자동 시작됩니다.
- **라이브 무대** — 아바타가 구역을 돌아다니고 O·X로 이동합니다. 초반 문제는 실시간으로, 후반 문제는 마감 후 일제히 공개해 눈치 답변을 막습니다.
- **맛보기 문제** — 1번 문제는 틀려도 탈락하지 않습니다(규칙 익히기용).
- **패자부활전** — 대기실 참가자만 답하고, 무대 생존자는 관전합니다. 무대 교대 연출이 나옵니다.
- **사진 문제** — 인물 사진을 띄우고 "이 사람은 …이다" 같은 문제를 낼 수 있습니다. 사진은 서버에 저장되어 외부 인터넷과 무관하게 표시됩니다.
- **채팅** — 폰에서 보낸 응원이 아바타 위 말풍선과 스크린 오른쪽 패널에 뜹니다. 욕설은 자동으로 가려집니다.
- **사회자 콘솔** — 큰 버튼 하나로 진행. 판정 취소, 라운드 취소, 참가자 복구·퇴장, 문제 편집, 참가자 CSV 내보내기, 전화번호 일괄 삭제.
- **복구** — 상태를 SQLite에 저장해 서버가 재시작돼도 이어집니다. 참가자는 같은 번호로 자기 자리에 복귀합니다.

| 대형 스크린 | http://localhost:5173/screen | 스크린 키 입력(기본 `screen`), 전체화면 권장 |
| 사회자 콘솔 | http://localhost:5173/host | PIN 입력(기본 `1234`) |

문제는 콘솔의 문제 탭에서 직접 넣거나 CSV로 가져옵니다. 예시는 [`questions/sample-questions.csv`](questions/sample-questions.csv)에 있습니다.

## 리허설 도구

참가자 없이도 혼자 연습할 수 있습니다.

```bash
npm run bots -- --count 10 --until 0   # 가상 참가자 10명(실력·고민 시간·채팅까지 흉내)
npm run autoplay                        # 사회자 조작까지 자동으로 한 판 진행
npm run simulate -- --players 100       # 부하 테스트(응답 지연 측정)
```

## 개인정보

휴대폰 번호는 경품 지급·본인 확인 목적으로만 수집하며, 사회자 콘솔과 CSV에서만 보입니다. 스크린·참가자 화면·로그에는 실리지 않습니다(예외: 결승 진출자 3명의 뒷번호 4자리를 호명용으로 표시). 행사 후 콘솔에서 일괄 삭제할 수 있고, 기본 7일이 지나면 자동 삭제됩니다.
