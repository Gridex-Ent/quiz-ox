# OX Quiz Cloud

진행자가 휴대폰에서 문제를 제어하고 노트북·프로젝터에 같은 진행 상태를 표시하는 OX 퀴즈입니다. 서버가 문제·타이머·행사 정보의 기준을 관리합니다.

> [!info] 2026-10-24 클라우드 전용 구현·로컬 검증 완료
> 행사/상품 이미지 설정·주먹/보자기·일반/번외10초·똑딱 효과음·진행자 팁을 구현했습니다. 164개 검사와 lint/build·실제 두 화면을 검증했습니다. Git 발행 결과는 후속 확인으로 기록합니다. 현재 Cloud Run 배포·가동 상태는 미확인입니다.

## 행사 진행

1. 진행실에 로그인합니다. 운영 배포는 허용된 운영자 Google 계정의 IAP 인증과 진행자 PIN을 사용합니다.
2. 행사 설정에서 **행사명·날짜·장소·안내 문구**를 저장합니다. 날짜는 `YYYY-MM-DD` 형식이며 비워 둘 수 있습니다. 저장된 정보는 대문과 종료 화면에 표시합니다. 같은 화면에서 **상품 소개 이미지**(PNG/JPEG/WebP/GIF,4MiB 이하)와 설명·캡션을 올려 미리 본 뒤 저장하거나 기본 이미지로 복원할 수 있습니다.
3. 진행실의 스크린 링크를 노트북에 열고 보조 화면으로 옮깁니다. 스크린에서 **소리 켜기**를 한 번 눌러 음향을 활성화합니다. 별도 공개 스크린은 연결 키로 읽기만 하며 Google 로그인을 요구하지 않는 구성입니다.
4. 대문에서 게임 방법을 안내하고 **시작하기 → 상품 소개 → 문제 공개**로 진행합니다.
5. **시간이 흐르는 동안 정답을 생각하고, 시간이 끝나면 O는 주먹·X는 보자기로 손을 듭니다.** 든 모양은 정답 공개까지 유지합니다. 선택형 문제의 첫 번째 보기는 주먹, 두 번째 보기는 보자기입니다.
6. 주제가2초 나타난 뒤 문제와 타이머가 자동 시작됩니다. 첫 주제는 워밍업이며 **일반·번외 문제 모두10초**입니다. 노래 문제는 시간 표시 없이 진행합니다. 스크린 음향을 켜면 매초 번갈아 나는 똑딱 효과음과 종료 효과음을 재생합니다.
7. **정답 공개**와 **다음 문제**를 직접 누릅니다. 시간이 끝나도 정답은 자동 공개되지 않습니다. 일시정지·타이머 재개·화면 가리기·대문·종료 화면도 제어할 수 있습니다.

문제·순서 저장이 성공하면 문제 선택 목록이 갱신됩니다. 편집 중 내용은 보관하며 서버 저장 완료 응답을 받은 상태와 구분합니다. 행사 정보·문제집·상품 수령 기록은 각각 검토하고 백업하세요.

## 유지하는 행사 자료와 기능

- **메인31문항:** 기존 문구·정답·순서·메타데이터를 보존합니다. 시작1번X·2번O, 제주어23~28번, 전기 국가29번, 파이썬 로고30번O, 대한전기학회 로고31번X가 포함됩니다.
- **번외33개:** 진행 런북에서 골라 출제하고 원래 본게임 위치·정답 상태·남은 시간으로 돌아옵니다. 복귀 후 타이머는 직접 재개합니다. 진행자 멘트는 진행실에만 표시합니다.
- **사진11문제:** 정답 공개 시점으로 설정된 사진5개는 문제 공개 중 숨깁니다. 공식 로고·사진의 출처와 권리 안내를 유지합니다.
- **상품·수령 기록:** 상품 소개는 업로드 이미지 또는 내장 기본 이미지를 크게 표시합니다. 기존28칸 이름·전화번호 기록, 별도 JSON 백업/복원·CSV 내보내기는 유지합니다. 명단은 인증된 진행실에서 관리합니다.
- **음향:** 합성 배경음·공개/타이머/종료 효과음과 공식 YouTube 재생을 유지합니다. 공식 영상이 포함된 문항은 인터넷 연결이 필요합니다.

행사명·날짜·장소·안내 문구는 대문과 종료 화면에 사용합니다. 기본31문항은 기존 행사 자료이므로 새 행사를 준비할 때 문제집도 함께 검토하세요.

## 개발 실행

Node.js22.13 이상이 필요합니다.

```powershell
npm ci
npm run dev
```

브라우저에서 `http://localhost:4190/`을 엽니다. 개발 실행기는 현재 개발 프로필의 무작위 PIN과 스크린 키를 처음 생성해 **`data/development/access.json`**에 보관합니다. 해당 파일에서 PIN을 확인해 진행실에 입력하세요. 같은 개발 프로필의 저장 상태는 다음 실행에 복원됩니다. 이 파일과 개발 상태는 Git에 포함하지 않습니다. 개발 서버는 localhost에만 바인딩합니다.

| 명령 | 용도 |
|---|---|
| `npm run dev` | 개발 프로필 준비와 localhost:4190 실행 |
| `npm run build` | 진행실·스크린 산출물 생성 |
| `npm test` | 공통 퀴즈·클라우드 검사 |
| `npm run lint` | 활성 소스 린트 |
| `npm start` | 설정된 환경에서 클라우드 서버 실행 |
| `npm run build:cloud` / `npm run test:cloud` / `npm run start:cloud` | 클라우드 명령 호환 별칭 |

## 운영 배포

운영은 전용 GCS 저장소와 Secret Manager의 PIN·스크린 키를 사용합니다. 진행실은 IAP로 허용된 운영자만 접근하고, 별도 스크린은 현재 공개 가능한 문제·정답 상태만 전달합니다. 서버 저장 실패·충돌은 성공으로 표시하지 않습니다. 기존 GCS 상태는 초기 문제집보다 우선합니다.

| 설정 | 내용 |
|---|---|
| `NODE_ENV` | `production` |
| `PORT` | 배포 플랫폼의 포트, 기본 배포값8080 |
| `MANUAL_GCS_BUCKET` | 운영 전용 비공개 버킷 |
| `MANUAL_GCS_OBJECT` | 기본 `manual/state-v1.json` |
| `MANUAL_HOST_PIN` | Secret Manager로 제공하는 진행자 PIN |
| `MANUAL_SCREEN_KEY` | Secret Manager로 제공하는 스크린 연결 키 |
| `PUBLIC_SCREEN_URL` | 별도 읽기 전용 스크린을 사용할 때의 HTTPS origin |

빌드 후 `npm start`로 실행하며 운영 환경은 GCS 설정이 필수입니다. Docker 이미지는 클라우드 진행실과 읽기 전용 스크린 구성을 제공합니다. 구체적인 리소스·권한·배포 인자는 [배포 절차](DOCS/planning/manual-cloud-deploy.md)를 따릅니다. 실제 PIN·키·토큰·명단은 소스나 문서에 넣지 않습니다.

2026-10-24 현재 새 코드의 Cloud Run 반영과 기존 서비스 가동 상태는 확인하지 못했습니다. 10월23일 인증 실패 이후 상시 가동·정지 결과를 재확인해야 합니다. 이전 예약이나10월22일 검증 기록을 현재 가동 상태로 해석하지 않습니다.

## 구조와 작업 현황

활성 패키지는 `ox-quiz-cloud` 단일 앱입니다. `cloud/`가 인증·상태·저장·공개 스크린 경계를, `web/src/quiz/`가 공통 모델·진행실·행사 정보·표시를, `web/src/cloud/`가 통신과 스크린을 담당합니다. 진행실 진입점은 `presenter.js`, 화면 틀은 `web/host-shell.html`, 기본 문제집은 `questions/default.json`으로 정리합니다.

전체 상태와 다음 작업은 [대시보드](DOCS/index.md), 설계는 [수동 클라우드 설계](DOCS/design/manual-cloud.md), 계획은 [로드맵](DOCS/planning/roadmap.md)을 참고하세요. 저장소는 [Gridex-Ent/quiz-ox](https://github.com/Gridex-Ent/quiz-ox)입니다.
