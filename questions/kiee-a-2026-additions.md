# 추가 문제 및 현재 실행 순서

> [!note] 최신 상태 — 2026-10-22
> 기본 문제집은 원이 문제를 5번에 추가한 **20문항**이다. 현재 사용자가 브라우저에서 저장한 순서·문구·보기는 기본값과 다르며 그대로 보존한다. 아래 19문항·음성 큐·임시 번호는 10월21일 기록이다. 최신 기본 배치·주제·사진·타이머는 마지막 항목을 따르며, 실제 진행 번호는 브라우저에 저장한 순서로 확정된다.

[한국전력공사 사내 극장 안내영상 제작 포트폴리오](https://kmong.com/portfolio/view/95381)의 원본을 공식 챗봇·한전ON·마스코트 소개 및 제작사의 3D 기본형과 대조했다. 이미지 출처는 제작 포트폴리오이며 공식 서버의 전신 배포본으로 주장하지 않는다. 기본4번·현재 사용자 저장6번에 해당하지만 문구·보기·정답·순서는 바꾸지 않는다. 공개 화면 캡션에는 정답 이름을 쓰지 않는다. 상세 출처·해시·권리 범위는 [자산 기록](assets/README.md#현재-사용--3d-기본형-전신-2026-10-22-교체)에 남겼다. 아래 GIF 사용 설명은 이전 기록이다.

## 이전 추가 기록 — 2026-10-21

## 3번 — 한국전력 배구단

**문제:** 한국전력 배구단의 이름은 전기스파이크다.

**보기:** O / X\
**정답:** X\
**제한시간:** 10초

**해설:** 한국전력 배구단의 이름은 빅스톰(VIXTORM)이다. 한국전력은 럭비단과 육상단도 운영한다.

사용자의 초반 배치 요청에 따라 맛보기와 전력 한자 문제 다음인 3번에 넣었다. 럭비단 정보는 해설에 반영했으며 별도 문항으로 추가하지 않았다.

**확인:** [한국전력 스포츠단 공식 홈페이지](https://www.kepco.co.kr/sports/index.do), [한국배구연맹 공식 경기장 안내](https://kovo.co.kr/tickets/court-view) (2026-10-21).

## 4번 — 한국전력 마스코트

**문제:** 한국전력 마스코트의 이름은 해피다.

**보기:** O / X\
**정답:** O\
**제한시간:** 10초

**해설:** 한국전력의 마스코트 이름은 해피다.

배구단 문제 다음인 4번에 넣었다. 문제 공개부터 해피 캐릭터 이미지를 함께 표시하며, 이미지는 단독 HTML에 내장해 오프라인에서 사용할 수 있다.

**확인:** [한국전력 공식 홈페이지 — 마스코트 해피](https://www.kepco.co.kr/home/service/privacy/boardView.do) (2026-10-21).

당시 이미지는 한국전력 캐릭터를 리터치한 [코글플래닛의 포트폴리오](https://www.cogulcontents.com/myboard/portfolio/91223)에서 확인한 단독 해피 GIF를 사용했다. 2026-10-22에는 위 3D 전신 JPEG로 교체했으며, GIF는 이관 비교용으로 보관한다. [이미지 출처 기록](assets/README.md)을 참고한다.

## 10번 — 노래

**문제:** 노래를 듣고, **에 들어갈 단어는 무엇일까요?

**보기:** 빛 / 전기\
**정답:** 빛\
**제한시간:** 5초

**해설:** 빈칸에 들어갈 단어는 ‘빛’이다.

주제는 **노래**이며 중간인 10번에 임시 배치했다. 데이터에서는 첫 번째 보기 `choiceO`가 빛, 두 번째 보기 `choiceX`가 전기이고 정답 키는 `O`다. 기본 설정에서는 왼손이 빛, 오른손이 전기다.

사회자가 노래를 먼저 부른 다음 이 문제의 **다음 · 큐**를 누른다. 문제 낭독이 끝나면 선택 타이머가 시작된다. 아직 노래 제목·가사 구절을 받지 않아 임의로 작성하지 않았다. 화면에 가사를 표시하려면 추후 지문에 추가한다.

## 당시 브라우저와 음성 파일 갱신 — 현재 사용하지 않음

- 저장된 문제를 먼저 **적용된 문제 백업**으로 보관한다.
- **행사 19문제 불러오기 → 문제 적용**을 누른다. 저장된 16·18문제는 사용자 편집 보존을 위해 자동 교체하지 않는다.
- 기존에 편집한 지문·대본은 백업과 비교해 다시 반영한다.
- 음성 제작용 JSON/TXT를 다시 내보낸다. 현재 기본 대본은 시작 1 + 문제 19 + 정답·해설 19 + 마무리 1 = **40개**다.
- 상품 소개는 시작 인사 큐에 포함되므로 문제 수와 대본 수는 늘지 않는다. 시작 대본이 바뀌었으니 최신 제작용 JSON으로 기존 `intro.wav`를 다시 제작한다. [상품 소개 안내](../README.md#시작-인사와-상품-소개)를 참고한다.
- 이전 `gpt-sovits-starter.zip`의 `default-cues.*`는 16문제용 34개 대본이다. 번호와 내용이 달라졌으므로 최신 음성 제작에는 새로 내보낸 JSON을 사용한다.

위 표는 **기본 문제집의 배치**다. 사용자가 저장한 현재 목록의 번호를 뜻하지 않는다. 일반 문제는 **주제2초 → 문제·타이머 → 수동 정답 → 다음**이며 현재 순서1~5번10초·6번부터5초다. 노래 빈칸 문제는 `timerMode: manual`로 시간 표시·카운트다운 없이 정답을 직접 공개한다. 첫 번째 문제의 주제는 문항을 바꾸어도 항상 워밍업이다. 문항 고유 주제는 보존하므로 다른 번호로 옮기면 해당 주제를 사용한다.

기존19문항의 지문·보기·정답·해설과 상대 순서는 기본 데이터에서 보존했다. 현재 사용자의 맞춤20문항은 이 기본값으로 자동 교체하지 않는다. 기본값을 새로 쓰려면 먼저 **적용된 문제 백업**으로 보관하고 **행사20문제 불러오기 → 문제·순서 저장**을 사용한다. 음성/TTS/낭독 큐는 사용하지 않는다. 과거 `번호 임시` 검토값과 배치 메모는 이력으로 보존하며, 현행 UI의 진행 번호는 저장한 순서로 표시한다.
