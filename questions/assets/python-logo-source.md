# Python 공식 로고

- 출처: [Python Software Foundation 공식 로고 페이지](https://www.python.org/community/logos/)

- 확인일: 2026-10-22
- 크기: 269 × 326px. 색·형상·방향·투명도를 바꾸지 않은 공식 PNG 원본이다.
- 설명: PSF는 이 기호를 ‘two snakes’ 로고라고 설명한다. 퀴즈는 Python 프로그래밍 언어의 로고에 관해 묻는다.
- 권리: Python 및 Python 로고는 Python Software Foundation의 상표다. [PSF 상표 사용 정책](https://www.python.org/psf/trademarks/), [공식 FAQ](https://www.python.org/psf/trademarks-faq/). 행사/앱의 로고로 사용하거나 공식 제휴를 표시하지 않는다.
- 사용 위치: 메인30번 정답 공개 단계의 확인 이미지. `imageReveal: answer`이며 문제 공개 전에는 표시하지 않는다.
