## 다운로드 검증

- HEAD가 위 원격 커밋과 일치한다.

- Windows Git의 자동 줄바꿈 변환을 새 clone에서만 해제하고 커밋 원본 바이트를 복원했다. 인덱스의 줄바꿈 메타데이터 갱신 후 staged diff 없음·작업 트리 clean을 확인했다.

- WAV **38개·29,326,472바이트**와 manifest의 38개 파일명이 모두 대응하며 누락이 없다. 38개 모두 RIFF/WAVE 헤더를 확인하고 SHA-256을 기록했다. 실제 음질·발화 내용 청취는 수행하지 않았다.

## 현재 19문항과의 차이

원격은 **18문항·38대본**이며 현재 프로젝트는 해피 문제를 추가한 **19문항·40대본**이다. 원격 1~3번은 로컬 1~3번, 원격 4~18번은 로컬 5~19번에 해당한다. 이는 문제 지문이 같은 위치를 비교한 결과이며 녹음 내용·해설·낭독 대본 일치까지 보증하지 않는다.

원격에는 해피 문제 2개 큐가 없고, 시작 상품 소개 대본과 문제 번호 안내 방식도 현재 로컬과 다르다. **38개를 현재 19문항에 파일명만 보고 연결하거나 번호를 바꿔 복사하지 않는다.** 추후 통합 시 실제 대본과 녹음을 대조하고 부족·변경된 큐를 제작해야 한다. 원격의 생성 WAV 다운로드는 원본 참고 음성이나 학습 모델을 받은 것과 다르며, 배포 문서상 원본 참고 음성·모델은 공개 배포 대상에 포함되지 않는다.

다운로드는 완료했다. 음성의 현재 19문항 통합·실제 청취·행사 리허설과 로컬 상품 기능을 원격 코드에 병합하는 작업은 수행하지 않았다.
