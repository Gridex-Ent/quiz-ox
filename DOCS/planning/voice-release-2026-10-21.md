# 18문제 음성 배포와 다른 PC에서 실행

배구단(3번)과 노래(9번)를 추가한 원격 main `5aee394`의 18문제를 기준으로 제작한다. 사용자의 최신 요청에 따라 문제 낭독은 번호나 ‘문제입니다’라는 안내 없이 바로 지문으로 시작한다. 연결용 파일명은 `question-01.wav` 등의 번호를 유지한다. 화면의 지문·선택지·정답·해설은 유지하고 `scriptQuestion`, `scriptAnswer`에 숫자·영문·기호의 한국어 낭독 문장을 명시했다. 낭독할 내용은 `questions/OX-audio-manifest.json`의 `cues[].text`와 일치하도록 구성하며, 이전 합성본의 문제 번호 안내는 제거했다.

## 다른 PC에서 사용

1. GitHub 저장소에서 **Code → Download ZIP**으로 받고 전체 압축을 푼다. 이 배포는 생성 WAV도 저장소에 포함한다.
2. 묶음의 `OX퀴즈.html`을 Chrome 또는 Edge에서 연다. GPT-SoVITS·Python·Node.js·GPU는 필요 없다.
3. 기존 브라우저에 문제를 저장했다면 먼저 백업한다. `questions/kiee-a-2026-offline.json`을 문제 편집에서 불러오고 **문제 적용**을 누른다. 별도 행사 전용 ZIP에서는 같은 파일을 `OX-questions.json`으로 제공한다.
4. 왼손은 첫 번째 보기(O), 오른손은 두 번째 보기(X)로 설정한다. 이름은 김희진·아스트라 기준이다. 기존 시작·마무리 대본을 편집했다면 기본 대본으로 돌리거나 제작용 JSON의 intro/closing 텍스트를 복사해 해당 대본에 저장한다.
5. **음성 파일 + 대본 JSON 함께 불러오기**에서 `audio/2026-10-21` 폴더의 WAV 38개와 `OX-audio-manifest.json`을 함께 선택한다. **38 / 38개 준비됨**을 확인한다. 별도 행사 전용 ZIP에서는 `audio` 폴더에 있다.
6. 준비 상태에서 **현재 대본 다시 읽기**로 미리 듣는다. 이 미리 듣기는 타이머를 시작하지 않는다. 실제 진행은 **이 문제 읽기** 또는 **다음 · 큐**로 시작한다.
7. 문제 낭독 종료 → 타이머 → 다음 큐에서 정답 공개 순서를 점검한다. **진행 멈춤** 후 다시 읽기 또는 수동 낭독 완료로 진행할 수 있다.

새로고침하거나 관리자 창을 닫으면 음성 연결이 사라지므로 5번을 다시 수행한다. 마지막 5초 숫자는 PC 음성이다. 음성과 대본은 왼손 O 기준으로 고정돼 있으므로 손 방향·이름·지문을 변경하면 대본 수정과 음성 재제작이 필요하다.

9번 노래는 사회자가 먼저 부른 뒤 문제 큐를 누르는 구성이다. 노래 음원은 포함하지 않는다. 6번 뒤 패자부활전 문항도 이번 18문제에 포함하지 않는다.

## 제작 및 검수 범위

로컬 RTX 4070 Laptop 8GB에서 GPT-SoVITS v2Pro를 사용했다. 긴 참고 음성 중 13개 구간 약 69.12초를 이용해 SoVITS를 8 epoch 학습했고, GPT는 기본 s1v3를 선택했다. 학습 전사는 자동 ASR 기반이며 사람이 확정한 전사가 아니다. 원본 참고 음성·학습 모델·설치 패키지는 공개 배포하지 않는다.

생성 결과의 자동 전사와 대본 비교는 오독·누락 후보를 찾는 보조 검사다. 유사도 점수는 발음·음색 품질 보증이 아니다. 전체 음성의 사람 청취와 행사 장비 리허설은 별도로 필요하다. ZIP의 검수 보고서를 함께 확인한다.

사용자는 2026-10-21 이 대화에서 **생성 음성의 공개 GitHub 업로드를 허용**했다. 이전 인계서의 비공개 전송 조건은 원본 참고 음성·모델에 계속 적용한다.
