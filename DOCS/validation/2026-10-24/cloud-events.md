# 클라우드 전용 범용 행사 퀴즈

사용자 후속 요구를 하나의 최신 버전으로 통합했다. 기존 참가자 앱·React 오프라인 화면·단독 HTML 실행기·낭독 WAV는 현재 tree에서 제외했다. 원격 기존4커밋과 로컬 원본211파일 snapshot/Git bundle을 보존하며, 클라우드 공통 엔진은 `web/src/quiz/`로 옮겼다. `npm run dev/build/test/lint/start`는 모두 클라우드 앱을 대상으로 한다.

## 구현과 저장 경계

- 행사 설정: 행사명·날짜·장소·안내 문구4필드. 관리자 인증/revision/CAS/ACK로 저장하고 대문·종료에 반영한다. 미저장 초안/늦은 ACK/다른 탭 충돌을 구분한다.
- 응답 모양: **O=주먹, X=보자기**. 선택형 첫/둘째 보기도 같은 모양을 사용한다. 안내 문구 아래 별도 한 줄로 표시하고 시간 종료 후 손들기를 유지한다.
- 시간: 일반·번외 모두 **10초**, 노래 문제는 시간 표시 없음. 기존31개 중26개의 seconds만5→10으로 바꾸고 다른 전체 필드·순서를 보존했다. 번외33개 JSON은 바이트 동일하다.
- 상품 이미지: PNG/JPEG/WebP/GIF4MiB 이하 업로드·미리보기·설명/캡션·저장·기본 복원. schema1에 nullable prize와 prizeVersion을 호환 추가한다. 상품 화면은 큰 이미지/캡션만 표시한다. 기존28칸 수령 기록은 별도로 유지한다.
- 성능: 사진은 초기/변경/복구에만 전달하고 일반 ACK/같은 버전 폴링에서 생략한다. 공개 상품 사진은 상품 단계에서만 전달한다. revision/표시 초가 같으면 큰 이미지 HTML을100ms마다 다시 만들지 않는다.
- 음향: 짧은 하강 삼각파를 번갈아 재생하는 똑딱 효과. 중복 초·놓친 초의 몰아 재생을 막으며 음소거/비활성·정지·종료 경계를 유지한다. 스크린에서 소리 켜기를 눌러야 시작한다.
- 사용자 제공 무대 인원 조정 팁을 진행실 관리자 패널에 원문 그대로 표시한다. 공개 DTO/스크린 번들에는 포함하지 않는다.

## 검증 완료

최종 **164/164 검사**, ESLint·빌드·diff 검사가 통과했다. 새 backend/업로드/초안/타탭 충돌/공개 경계/큰 이미지의 반복 전송 방지/단계 HTML 캐시/효과음 합성과 기존 문제·명단·런북·영상 회귀를 포함한다. 예전140개 검사는 이전 버전 이력이며 이번164개와 구분한다. Docker 두 target 설정과 허용목록 소스 패키지는 별도로 검사하며, 이미지 실제 Cloud Build 성공은 아직 주장하지 않는다.

CUA로 localhost:4190의 실제 진행실과 별도 스크린을 조작했다.

1. 행사4필드를 저장하고 새로고침 후 복원, 대문·종료의 이름/날짜/장소/안내 반영을 확인했다.
2. 휴대폰 viewport390×844(client폭375, 스크롤바 제외)의 폼에 가로 넘침이 없었다. 대문1366×768·1920×1080에서 넘침 없이 이름·한 줄 모양 안내·**본게임/번외 모두10초**가 보였다.
3. 기본 상품 PNG2,631,788바이트를 실제 파일 선택으로 업로드하고 설명·캡션과 함께 저장했다. 새로고침 후 값이 남고 별도 스크린에서1536×1024 이미지가 실제 로드됐다. 특정 금액/등수 목록은 표시하지 않았다.
4. 후반31번과 저장된 번외를 출제해 주제2초 후 자동10초와 주먹/보자기 보기를 확인했다.31번 정답은 수동X이며 이전 정답 전 이미지 숨김도 유지됐다.
5. 스크린 음향 켜짐 표시와 실제 오디오 활성화 경로를 확인했고 합성 음형/중복/10초 효과 시퀀스는 자동 검사했다. 현장 스피커를 통한 청취·정밀 지연 계측과 구분한다.
6. 진행자 팁 원문이 관리자 패널에 있고 스크린에는 없음을 확인했다. 번외에서 본게임 대문/index0으로 복귀했다. 주제/문제 전환 경계에서 대문 명령1회가 완료되지 않아 확정 상태 관찰 후 명시적 본게임 복귀로 확인했으며 무지연·자동 재시도 성공으로 표현하지 않는다.

프로젝터/실물 휴대폰 전체 리허설은 별도다. 브라우저 크기 override를 원복했다. [검증 JSON](cloud-events.json).

## GitHub와 운영 반영 구분

origin은 Gridex-Ent/quiz-ox로 변경하고 원격 `f20163a`에서 통합 branch를 만들었다. 원본 작업폴더는 reset/clean하지 않았고 snapshot211개 해시를 모두 확인했다. 비밀값·명단·개발 접근 파일·런타임 상태·Git bundle은 ignored data에만 둔다. Git 커밋/push 결과는 후속 확인 기록으로 확정한다.

현재 운영 Cloud CLI는 재인증을 요구한다. 이번 코드의 Cloud Run 배포와 기존 가동 상태는 미확인이다. 이 소스/로컬 UI 검증을 새 운영 배포로 해석하지 않는다.
