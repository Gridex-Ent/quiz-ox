녹음 음성 불러오기 · MP3 / WAV

HeyGen에서 만든 음성을 내려받아 연결하세요. 생성된 교수님 음성 파일은 아직 포함되어 있지 않습니다. 파일을 연결한 대본만 녹음 음성으로 재생하고, 나머지는 PC 음성으로 읽습니다.

1. 아래 JSON의 각 text 또는 전체 대본 TXT를 사용해 음성을 만드세요.
2. 파일 이름을 intro.wav, question-01.wav, answer-01.wav, …, closing.wav로 바꾸세요. MP3도 가능합니다.
3. 음성 파일과 제작에 쓴 JSON을 함께 선택하세요. JSON 없이 선택할 때는 녹음과 현재 대본이 같은지 직접 확인하고 확인란을 선택하세요.

불러온 파일별 상태

JSON은 제작용 대본과 현재 대본의 글자를 비교합니다. 실제 음성 내용은 자동 검증하지 않으므로 행사 전에 각 파일을 직접 들어 확인하세요. 대본이 바뀌면 해당 녹음은 사용을 멈춥니다. 재생 실패 시 “현재 대본 다시 읽기”로 재시도하거나 “PC 음성으로 읽기”를 누르세요.

불러온 음성은 현재 창의 메모리에만 보관됩니다. 창을 닫거나 새로고침하면 파일을 다시 선택해야 합니다. HTML·문제 백업에 음성이 저장되지 않으며, 원본 파일은 PC에 보관하세요. 파일은 서버로 업로드되지 않습니다.

아스트라 · 음성 · 음악 설정

설치된 한국어 음성을 확인하는 중입니다.

마이크 꺼짐. 음성 큐는 한국어 기기 내 인식을 지원하는 브라우저에서 사용합니다.

녹음이 없는 대본과 마지막 숫자는 PC 음성을 사용합니다. 녹음은 파일의 원래 속도로 재생합니다. 원본 프로젝트의 실시간 AI 통화와는 별도입니다. 배경음악과 효과음은 내장되어 있습니다. 낭독 중에는 음악을 낮추며, 마이크가 켜져 있으면 큐 대기 중 음악을 쉽니다.

문제 준비 · 편집 · 백업

대한전기학회 A부문회 행사 문제집 18문제를 반영했습니다. 원본의 후보·임시 배치 상태는 관리자에게만 표시됩니다. 수정 후 “문제 적용”을 누르세요.
